# Amazon A+ Content

**Purpose:** Design high-converting Amazon A+ content using structured research, persuasion principles, and visual storytelling. Final output is a Visual Brief Handoff (Section 9) that feeds the `amazon-aplus-visual-assets` protocol.

**When to run:** New product launch, listing optimization, or competitor replacement on Amazon.

**Inputs:** Product reference images (primary photo mandatory); product information; access to competitor listings and reviews.

**Output:** Nine-section A+ content package — research, positioning, module copy, and the Section 9 Visual Brief Handoff.

**Skills called:** none (cookware insight library embedded at Step 3B)

**Version:** 2.1

---

## Purpose

Design high-converting Amazon A+ content using structured research, persuasion principles, and visual storytelling.

This protocol combines:

• competitor research  
• customer review mining  
• cookware insight library  
• objection analysis  
• conversion narrative design  
• A+ module mapping  
• conversion psychology  
• visual storytelling  
• copywriting

The goal is to produce A+ content that functions as a **high-conversion landing page within the Amazon listing.**

The final output of this protocol — the **Visual Brief Handoff** — feeds directly into the **Amazon A+ Visual Assets Prompt Creator (`amazon-aplus-visual-assets`)**, which generates all AI image generation prompts.

# RUN COMMAND

Run CANON CONTENTDESIGN Amazon A+ for \[Product Name or ASIN\]

Example:

Run CANON CONTENTDESIGN Amazon A+ for ASIN:B0XXXXXXXX

# STEP 0 — PRODUCT IMAGE UPLOAD

Before asking any questions, ask the user to upload product reference images.

**Required:**

• Primary product photo (mandatory — front-facing, clean background preferred)

**Optional but recommended:**

## Visual Suggestion Format

Each module's Visual Suggestion begins by selecting a **Visual Type**, then follows the format for that type.

Visuals must be differentiated across modules — no two modules should share the same scene, angle, or concept. Use the Insight Source field to anchor each suggestion to a specific finding from the research.

### Visual Type Options

| **Type**                    | **When to Use**                                     |
|-----------------------------|-----------------------------------------------------|
| **Photography — Lifestyle** | Emotional scenes, usage moments, brand story        |
| **Photography — Studio**    | Product hero, detail, material close-ups            |
| **Photography — Action**    | Product in use, cooking, handling                   |
| **Annotated Photo**         | Feature callouts overlaid on product image          |
| **Infographic / Chart**     | Comparison data, performance stats, spec breakdowns |
| **Diagram / Illustration**  | Cross-sections, technical explainers, process flows |
| **Graphic / Text-led**      | FAQ, reassurance, bold claim with minimal visual    |

# STEP 9 — COPYWRITING RULES

Apply these rules to all module copy:

• Concise — no padding  
• Benefit-focused — lead with outcome, not feature  
• Avoid marketing fluff ("best in class", "revolutionary", "game-changing")  
• Prioritize clarity over clever wording  
• Customer Voice copy must mirror actual language found in reviews

## SECTION 9 — VISUAL BRIEF HANDOFF

### Handoff Instructions

**How to use this section:**

1.  Sections 9A, 9B, and 9C are the **session context** — they establish product, positioning, and visual strategy. Generate and output all three as a single combined block, then **stop and wait**.

2.  After outputting the Session Context block, say:

> "Your session context is ready. **Copy the block above.** When you're ready to generate image prompts, start a new chat and run the Visual Assets Prompt Creator. Paste this block as your first message — it will load all context automatically."

3.  After the user acknowledges, prompt:

> "When you're ready, I can also show you each module's Visual Brief individually, formatted for pasting into the Visual Assets Prompt Creator one at a time. Would you like that now?"

4.  The user will paste a single Visual Brief block from Section 9D. Generate the composition plan and Per-Image Payload for that module only.

5.  After generating, ask:

> "Does this look correct? Ready to move to the next module, or are there any adjustments?"

6.  Only after the user confirms, ask:

> "Please paste the Visual Brief for the next module."

7.  Repeat steps 4–6 until all modules are complete.

**Do not pre-generate all module payloads at once. Process one module at a time.**
